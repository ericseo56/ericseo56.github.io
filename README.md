# Eric Seo

Personal portfolio for Eric Seo, an Electrical and Computer Engineering student at Cornell University. Built with semantic HTML, CSS, and a small JavaScript file. No build step or third-party runtime dependencies.

## Local preview

Run `python -m http.server 8080` from this folder, then open http://localhost:8080.

## Editing

- `index.html`: biography, projects, experience, education, and contact links.
- `styles.css`: responsive layout, typography, and colors.
- `script.js`: mobile menu, navigation state, and portrait loading.
- `assets/profile.jpg`: Eric's portrait from the public [Cornell XR team page](https://cornellxr.com/team/). LinkedIn blocked unauthenticated image retrieval.
- `assets/eric-seo-resume.pdf`: downloadable resume.

## GitHub Pages

The site is served directly from the `main` branch at `/` at https://ericseo56.github.io. Repository: https://github.com/ericseo56/ericseo56.github.io. In repository Settings > Pages, select **Deploy from a branch**, then **main** and **/(root)**.

All internal asset URLs are relative, so the site also works as a project site.
